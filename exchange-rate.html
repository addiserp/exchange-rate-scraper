How this works: most Ethiopian bank sites load their rates with JavaScript a few seconds after the page itself finishes loading, so a background script periodically opens each bank's page in a real (headless) browser, waits for the numbers to appear, and saves them here — that's what actually keeps this table current. "Refresh now" additionally re-checks, instantly, the few banks whose sites show a rate without needing that wait; it never overwrites a good number with "Unavailable" for the rest. A dash (—) means that bank's rate wasn't available at the last check. These figures, including SWIFT/BIC codes, are informational only — always confirm the exact rate and code with the bank directly before making a transaction or wire transfer.
