# Exchange Rate Scraper

This project scrapes exchange rate data and exposes it through a simple PHP API.

## Included

- `exchange-rate.html` – frontend page for displaying exchange rates
- `api/` – PHP endpoints for retrieving and uploading exchange rate data
- `config/` – configuration examples and upload token setup
- `scripts/` – Python scraper for fetching rates

## Setup

1. Review the configuration files in `config/`.
2. Install Python dependencies from `scripts/requirements.txt`.
3. Run the scraper script as needed.
4. Use the API files with your server environment.

## Notes

Keep actual secrets out of version control. Use the example config files as templates.
